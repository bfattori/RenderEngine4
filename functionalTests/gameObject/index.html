  • Stateful Sprite Objects

    StatefulSprites are sprites that include states for animation transitions. The sprite animations are stored in a look-up table that define the transition states. Changing from one state to another automatically transitions without needing to manually time and specify the states.

    To break this down, let's assume you have the following: a running, walking, standing, and crouched animation for the two horizontal directions (left & right) and you want to go from standing to running, or running to a crouch.

    The state table defines states and the valid entry states that allows the engine to calculate a transition graph through available states to achieve the desired state. An example state table for the left direction might look like this:

    State Description Entry states
    Run-Left Running to the left at full speed Walk-Left
    Stand-Left Standing, facing to the left Walk-Left or Crouched-Left
    Walk-Left Walking, facing to the left Run-Left or Stand-Left
    Crouched-Left The player drops into a crouched position, facing left Stand-Left

    So, for example: To go from a current state of Crouched-Left to the Run-Left state, with a smooth transition to achieve the end state, the the transition graph is calculated as: Crouched-Left —> Stand-Left —> Walk-Left —> Run-Left

    In the game, assuming a sprite in the "Crouched-Left" state, one would simply use sprite.transitionTo('Run-Left'); and the engine fills in the animation to transitions for you.
