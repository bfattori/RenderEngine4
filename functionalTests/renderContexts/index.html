  • The Intermediate Language

    Your game will program against the high-level API of the RenderContext to generate visual output. The RenderContext abstracts away the complexities of generating output to a surface (canvas, webgl, etc.) by producing an Intermediate Language (IL). The IL is passed to the renderers to generate the actual rendered output.

    The IL has a syntax that is similar to Assembly Language, comprised of an operator like LINE, POINT, COLOR, and SHAPE followed by zero or more operands. The renderers interpret these commands to produce output using the renderer's API. Addressing Canvas2D or WebGl directly can be eliminated entirely.

  • Vector Rendering w/Canvas
    A simple example showing the RenderContext and CanvasRenderer used for vector drawing. Vector rendering is comprised of lines, points, line and curve paths, and primitive shapes and polygons to generate imagery. This demonstrates using the engine to render a static layout to a Canvas 2d context. It also demonstrates the vector-based font included with the engine.

    This demonstrates the RenderContext and CanvasRenderer raster drawing. Raster rendering includes Sprites, Tiles, and TileMaps that are common in pixel-based games.
