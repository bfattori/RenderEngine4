Render Contexts - Static Tests

  • Vector Rendering w/Canvas
    A simple example showing the RenderContext and CanvasRenderer used for vector drawing. Vector rendering is comprised of lines, points, line and curve paths, and primitive shapes and polygons to generate imagery. This demonstrates using the engine to render a static layout to a Canvas 2d context. It also demonstrates the vector-based font included with the engine.
  • Raster Rendering w/Canvas
    This demonstrates the RenderContext and CanvasRenderer raster drawing. Raster rendering includes Sprites, Tiles, and TileMaps that are common in pixel-based games.
