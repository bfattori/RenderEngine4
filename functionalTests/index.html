RenderEngine4 - Functional Tests

  • The RenderEngine4 - A walk through of the engine components, how they work together, and how to build a game with them.
  • Game Objects & Component parts - The core object for game building, the GameObject eliminates monolithic design through composition. The various component parts grant atomic functionality to game objects as needed.
  • Resource Management - Included with the engine is an extensible resource loading system, providing classes to load imagery, tiles, sprites, tile maps, and more.
  • Collisions - Two types of systems work together to determine object collisions. The Broadphase system identifies objects near each other, while the Narrowband system determines actual interation.
  • Render Contexts - The render context determines the type of game you'll make, either vector or raster. Contexts are paired with a renderer like Canvas 2d or WebGl for flexibility.
  • Sounds - To provide flexibility, the RenderEngine4 includes audio systems ranging from the simplest to spatially rendered sounds.
  • Particle Engine - The RenderEngine4 comes with a full-featured particle system that runs in either the main thread or in WebWorkers to improve performance.
