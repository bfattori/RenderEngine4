RenderEngine4 - Functional Tests

  • Render Contexts - The render context determines the type of game you'll make, either vector or raster. Contexts are paired with a renderer like Canvas 2d or WebGl for flexibility.
  • Game Objects - The core object for game building. It eliminates monolithic design through composition. The various component parts grant atomic functionality to game objects as needed.
  • Particle System - The RenderEngine4 comes with a full-featured particle system that runs in either the main thread or in WebWorkers which can improve performance.
