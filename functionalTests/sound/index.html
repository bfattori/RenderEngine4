Sound Systems

  • The SoundSystem class

    The base class for all sound systems in the engine, SoundSystem provides the basic interface for all other sound systems, such as playback, pausing, looping, and more.

  • Browser Audio System

    The BrowserAudio system is the simplest is the most broadly supported sound playback across devices. This has several limitations, but can be used widely when the type of destination platforms are unknown.

  • Web Audio System

    More flexibility is available with the WebAudioSystem which uses the Web Audio API for enhanced processing and playback. The Web Audio API may not be supported on all platforms.

  • Spatial Audio System

    The SpatialAudioSystem extends the WebAudioSystem and is intended to provide the most flexibility and features for a game. It supports sound posititioning, doppler shift, and other sound processes. This play back system may not be supported on all platforms.
