Resource Management

  • The ResourceLoader class

    ResourceLoader is the base class for all resource loaders in the engine. It handles various data types including text, JSON, and Blob to provide the flexibility to load many types of resources for your game. ResourceLoader, by itself, is just the foundation. The sub-classes provide the actual functionality your game needs.

  • Image Resources

    Loads images of various web formats. This class is used by the TileMap, TileSheet, and SpriteSheet which are for loading pixel graphics (bitmaps) into the game.

  • Sprite Sheets & Sprites

    A SpriteSheet loads sprite definition files (JSON) that describe the bitmap containing the sprites, and the individual sprite definitions. Sprite resources can be static (like a Tile) or they can be animated. A few animation types, such as loop and bounce, are provided.

  • Tile Sheets & Tiles

    TileSheets are similar to the SpriteSheet except the tile definitions are all static. No animations are possible with tiles. Tile resources are simply defined by the position in the backing bitmap, and their dimensions.

  • Sound Sheets & Sounds

    What is a game without sound? Managing sounds is done with SoundSheets that define the sounds the engine can play back, and various configuration properties such as volume, pitch, and looping. Sound resources are used by your game, with a SoundSystem, to play back sounds in different styles.

  • Tile Maps

    TileMap is the base class for the different type of game world maps. A TileMap defines the type of map, properties for the placement of tiles, and other mechanisms that are foundational to game world development.

    Three types of TileMap are provided with the RenderEngine4:

    Type Description
    GridMap The grid map is a simple layout. Divided along the X and Y axis at equal sizes, the grid map places tiles along any of the map divisions. This type of map is good for puzzles and other rigid layouts. The GridMap is limited to the GameWorld viewport.
    PlatformerMap This style of map is similar to the GridMap but provides the flexibility to create tile layouts with spans and blocks of tiles, triggers, moving tiles, and more. PlatformerMap can be larger than the world viewport.
    IsometricMap This map uses an isometric projection to create a 3D effect. This type of map is good for creating large worlds and employs procedural or rules-base tile generation and placement. The IsometricMap is intended to be larger than the world viewport and provides for streaming map parts in as needed and discarded when not.
