RenderEngine4 Demo Engine

Minimal stand-in for the real engine, so the RenderEngine4 Inspector DevTools panel can be exercised end-to-end. It uses the exact same bridge + protocol files the real engine will. This file is not part of the shipped extension — it lives in examples/ purely for testing.

Load this page, open DevTools (F12), and click the RenderEngine4 panel. Start/Stop/Step work both from the panel toolbar and from here.
