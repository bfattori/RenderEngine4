# RenderEngine4 - DevTools extension

This is an experimental extension developed for Google's Chrome DevTools. It's intended
to be a developer's debugging tool for their game in realtime. You can inspect and modify
Engine object's properties, pause and resume the Engine, and inspect the game's state.

## Installation

1. Navigate to `chrome://extensions/` in Google Chrome.
1. Toggle the **"Developer mode"** switch in the top-right corner.
1. Click the **"Load unpacked"** button on the left and select the `./RenderEngine4/Inspector` folder.
1. Open any webpage, press `F12` or `Ctrl`+`Shift`+`I`
